# Evidencias

Catálogo completo: SQAP, Sección 12. Aquí se copian las evidencias que deben durar toda la gestión, porque Jenkins solo
conserva los últimos 30 builds:

- `sprint1/`: informe de pruebas del Sprint 1 (Jest, Vitest, Cypress, métricas M01–M16).
- `vX.Y.Z-rc.N/`: informes JUnit y cobertura, videos de Cypress, dashboards de JMeter del release candidate.
- `usabilidad/`: planilla de la prueba con 5 profesores y cuestionarios SUS anonimizados (M11, M12).
- `disponibilidad/`: exportación mensual del monitor (M13).

Nunca se suben datos reales de estudiantes.
